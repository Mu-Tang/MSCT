# MSCT
MSCT is a machine learning-based system for **aircraft landing gear load prediction**, evaluation, and visualization.  
The project integrates model training, load prediction, and error visualization modules.

> Note: Due to data confidentiality, the original datasets are not provided. You will need to prepare your own data.

---

## 🚀 Features
- Load equation modeling and learning
- Machine learning models (e.g., Gaussian Process, MCA-MLPSA)
- Evaluation metrics calculation
- Prediction and relative error visualization
- Modular code structure, easy for extension

---


---

## 🛠️ How to Run

1. Clone this repository:

```
git clone https://github.com/your-username/LandingGearProject.git
cd LandingGearProject
```

2. Install required packages:

```
pip install -r requirements.txt
```

3. Prepare your dataset according to the expected format described in `dataloader.py`.

4. Train or evaluate the model:

```
python main.py
```

Generated figures will be saved in the specified output folder.

---

## 📦 Requirements

- Python >= 3.7
- numpy
- matplotlib

(You can install all dependencies via `requirements.txt`.)

---

## 📈 Example Output

When the script runs successfully, it will produce:
- Training logs
- Evaluation metrics (e.g., MAE, RMSE)
- Prediction vs. Ground Truth plots
- Relative Error plots

> Plots will be automatically saved as high-quality `.png` files.
